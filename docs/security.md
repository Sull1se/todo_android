# Todo 安全说明

## 支持范围

旧版本不单独维护。数据库迁移下限为 schema 4，更早的历史数据库会被拒绝打开并保留原数据。

## 本地数据边界

- 应用数据（清单、任务、偏好）保存在本机 Room 数据库与应用私有目录；[主 Manifest](../app/src/main/AndroidManifest.xml) 未声明网络权限，应用代码未接入网络服务。
- 本地导入导出通过系统 Storage Access Framework 进行，由用户显式选择文件；备份 JSON 不包含凭据，导入时严格校验必需字段与引用完整性。
- **系统备份与设备迁移（APP-006）**：当前 Manifest 允许系统备份（`allowBackup="true"`），但备份规则与数据提取规则仍为模板，实际备份行为未验收，该策略按维护者决定无限期暂缓（状态见 [当前问题](quality.md)）。不能据此承诺数据绝不会进入系统备份或设备迁移；对数据敏感的用户可暂关闭系统级备份或等待该问题解决。
- 不存在云端同步、遥测或第三方数据采集。

## 签名身份

- 本项目对外发布的 Release APK 由仓库所有者的专用发行密钥签名；**公开证书 SHA-256 指纹基线**保存在 `scripts/quality/release-certificate.sha256`（当前值 `936961c6acce74ade345fab6cc81902096d8f59fa73db3356fbec49f0667695d`）。安装 Release 产物前应核验签名指纹与基线一致。
- 私钥、密钥库与密码不属于本仓库内容，且已被忽略规则排除；任何要求你提交或导出私钥的“贡献流程”都不是本项目的行为。
- Debug 构建使用标准 Android 调试证书（或本地自定义 `debug.keystore`），仅供开发验证，不作为对外交付身份。发行签名与调试签名的 APK 互不能覆盖安装，属预期边界。
- **他人 Fork 并自行构建 App 时，请使用自己的签名私钥并修改包名（`applicationId`）**：本仓库的发行签名身份与包名属于本项目，直接沿用会造成安装冲突与签名身份混淆。Fork 建立自己的发行身份时，应在本 Fork 仓库明确登记独立的证书指纹基线与版本，不得在本项目仓库替换基线以绕过核验。
