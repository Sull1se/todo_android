## 阅读与事实优先级

- 操作约束以根入口和维护规则为准；现行行为由主题文档说明并链接实现。
- 代码与文档冲突时核对证据：修正过时描述；若违反已有需求或数据保护要求，则在状态页登记缺陷，不能把缺陷改写为目标。
- 每类知识只有一个主文档。其他位置用摘要和相对链接引用，不复制完整配置或步骤。
- 一般任务不另建独立计划或每任务日志；进入独立方案编写流程时按对应 Skill 在 `docs/` 保存交接方案。已完成修改由 Git 追溯，长期结论回到主文档；验收结果与已解决问题进入统一历史文档，当前问题页只保留未闭环条目。
